REGISTRE LOCAL D'ACTIVITATS EXTRAORDINARIES (mode ACT_EXTR)
==========================================================

Aquesta carpeta guarda el registre local de les activitats extraordinaries
(Decret 112/2010) que portes amb el mode "Activitats extraordinaries (ACT_EXTR)"
del programa.

QUE HI HA
---------
- activitats-extraordinaries.json : el registre amb les dades de cada activitat
  (titular, adreca, aforament, respostes de classificacio del Decret, estat de
  cada punt de documentacio i historial de requeriments/informes generats).

IMPORTANT (PRIVACITAT)
----------------------
El .json conte DADES PERSONALS (titulars, adreces). NO es puja mai a GitHub:
esta al .gitignore. Es queda nomes al teu PC.

SINCRONITZAR ENTRE PCs
----------------------
Si vols tenir el mateix registre a la feina i a casa, copia a ma el fitxer
activitats-extraordinaries.json d'aquesta carpeta entre els dos PCs.
